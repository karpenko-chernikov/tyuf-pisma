# ТЮФ — письма

Локальное веб-приложение для книги школ/центров и персональных PDF-рассылок Открытого Всероссийского ТЮФ. Два–три пользователя, общая SQLite-база.

## Возможности

- Книга школ и центров с правками в таблице и на карточке
- Рассылки: HTML или PDF-шаблон, подстановка `{{greeting}}`, `{{school}}`…
- Отправка email с сайта (SMTP-ящики в Кабинете)
- Журнал действий, мягкое удаление школ с восстановлением

## Запуск локально

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env   # задайте SECRET_KEY и пароли
./run.sh
```

Откройте http://127.0.0.1:8000
